## Preview 재배포 빌드 오류 조치
- 사용자 환경변수 등록 후 e654920을 push해 Preview 재배포를 시작했다.
- Vercel 빌드 로그에서 기존 Outfit 폰트의 Turbopack 모듈 해석 오류 8건을 확인했다. 배포용 build 명령을 next build로 변경해 기본 빌더로 전환했다. 개발용 dev 명령과 화면 코드는 유지했다.
- 새로운 빌드와 실제 답변·DB·알림 결과는 후속 확인 예정이다.
- ef5cf29의 Preview 빌드는 정상 완료됐다. 실제 질문 2회는 Gemini 503으로 실패했고, 같은 키의 모델 조회는 성공했다. 직접 Interactions 요청도 시간 초과로 실패했다.
- 사용자 지시에 따라 Vercel GEMINI_MODEL을 gemini-3.5-flash-lite로 변경하고 Preview 재배포를 시작했다. 실제 답변 생성 여부는 후속 확인 중이다.
- Lite Preview에서 같은 질문에 문서 기반 답변이 생성되고 화면 로딩이 종료됐다. 서버 로그에서 Telegram 발송 완료도 확인했다.
- MongoDB는 기존 주소의 DNS 조회 실패로 대화 기록 저장이 실패했다. 로컬 기본 DNS·Google DNS·Cloudflare DNS 모두 같은 오류를 반환했다. 검색 결과의 중지·삭제·주소 오류 가능성을 참고했으며 Atlas 로그인 후 상태 확인이 필요하다. 운영 배포는 아직 전환하지 않았다.
- 실제 사용 모델과 일치하도록 서버 기본 모델과 README를 Lite로 갱신했다. 모델명은 환경변수로 계속 변경할 수 있다.
- Atlas 로그인 후 기존 무료 클러스터가 장기 미사용으로 자동 중지된 것을 확인하고 재개했다. 최신 Lite Preview의 실제 질문에서 답변 생성, MongoDB 대화 저장, Telegram 발송이 모두 성공했다. 사용자 요청에 따라 운영 배포를 진행한다.
